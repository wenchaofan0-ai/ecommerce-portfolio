# 车商线索与车源匹配助手（产品作品原型）

这是一个面向二手车顾问的轻量产品原型：把客户的自然语言需求整理为结构化线索，对模拟库存做透明规则初筛，并显示匹配理由、未满足条件、待追问信息和建议下一步。

## 在线演示

[打开车商线索与车源匹配助手](https://wenchaofan0-ai.github.io/ecommerce-portfolio/used-car-matcher/index.html)

## 运行

直接双击 `index.html`，用 Chrome 或 Edge 打开即可；无需安装软件、登录或联网。选择示例线索后点“分析线索并匹配车源”，也可以修改预算、车型和城市自行试用。

## 数据和能力边界

- 页面中的客户线索、车辆、价格、里程和匹配分数都是为演示而编写的模拟数据，不代表懂车帝内部业务、真实车源或市场统计。
- 当前是浏览器内的确定性规则原型，没有连接大模型、线上库存、客户系统或真实业务流程。
- 匹配分数是产品演示用启发式规则，不是经业务验证的模型分数；车况、手续、价格和可售状态必须人工核验。
- PRD 中涉及的用户痛点、流程价值和指标均是待验证假设；没有开展真实用户访谈或线上 A/B 测试。

## 文件

- `index.html`：可交互原型。
- `PRD.md`：问题假设、目标用户、MVP、规则、指标和验证计划。
- `test_cases.csv`：模拟场景与预期行为。
- `resume_bullets.md`：真实、克制的简历写法和面试说明。

## 后续验证顺序

1. 找 3–5 位二手车顾问做 15 分钟访谈，验证线索整理、库存初筛和追问建议哪一步最费时。
2. 用脱敏或自建样例补齐边界情况，和顾问一起检查字段及排序是否合理。
3. 做 5 次可用性走查，记录任务完成情况、误解点和修改记录。
4. 再决定是否值得接入真实库存或大模型；在获得授权前不要导入客户个人信息。
